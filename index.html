📱 How to install the Root CA

Android

Settings → Security → Encryption & credentials → Install a certificate → CA certificate

iOS / iPadOS

Download via Safari → Settings → Profile Downloaded → Install → Enable Full Trust in Certificate Trust Settings

Windows

Double-click the file → Install Certificate → Local Machine → Trusted Root Certification Authorities

macOS

Open in Keychain Access → System → drag file → set to "Always Trust"

Linux (Debian / Ubuntu)

sudo cp root-ca.pem /usr/local/share/ca-certificates/ && sudo update-ca-certificates

Nginx / Apache Server

cat leaf.pem root-ca.pem > bundle.crt, then point ssl_certificate to bundle.crt
