Export your signed certificate as PEM, fullchain, or CRT — ready for your web server.

About the download options

  • → Certificate (.pem) — the leaf certificate only. Use for verifying or inspection.
  • → Fullchain (.pem) — leaf + Root CA bundle. This is what Nginx / Apache / Caddy / Traefik expect for ssl_certificate.
  • → Certificate (.crt) — same as .pem but with .crt extension (some hosts require this).
  • → Private key — was shown once at issuance. If you lost it, ask your admin to retrieve it via the Admin panel.
